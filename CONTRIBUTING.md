# Contributing to AI Learning Studio

Thank you for helping improve AI Learning Studio.

## Good contribution areas

- mathematics lessons and mathematically correct visualizations
- Pascal/C code-reading examples that contributors have the right to share
- Python learning activities
- Image AI and webcam experiments
- robot simulator environments
- hardware adapters with safe defaults
- Thai/English documentation
- accessibility improvements for deaf and hard-of-hearing learners

## Contribution flow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Test the application and relevant learning activity.
5. Open a pull request explaining the educational goal and tests performed.

## Source/data rights

Do not commit proprietary compiler files, copyrighted legacy archives, ROMs, binaries, datasets, images, or source code unless redistribution is permitted. In particular, do not add unverified Turbo C/Turbo Pascal archives to this repository.

## Robot safety

New hardware integrations should default to simulation or STOP, use explicit enablement for physical output, document the protocol, and provide a clear emergency-stop path.
